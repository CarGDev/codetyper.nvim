# Codetyper.nvim — LLM Context

> Repository: https://github.com/cargdev/codetyper.nvim
> License: MIT
> Runtime: Neovim 0.9+

## Purpose

Codetyper.nvim is a Neovim coding partner. It builds bounded prompts from a
selection, cursor position, or `/@ ... @/` tag, sends them through an explicit
provider, and applies reviewable edits. The plugin keeps external context and
interactive actions behind explicit, validated boundaries.

## Provider model

The supported providers are `copilot`, `ollama`, `claude`, and `openai`.

- Copilot uses OAuth exchange credentials and may receive native structured
  tools only for eligible project tasks and tool-capable models.
- Ollama uses a configured local HTTP host and can be the automatic fallback
  when Copilot authentication is unavailable.
- Claude reads only `ANTHROPIC_API_KEY` from the inherited environment. It is
  non-streaming and does not receive native tools.
- OpenAI means ChatGPT Plus/Pro subscription OAuth, not `OPENAI_API_KEY`.
  Tokens remain session-only and the provider is non-streaming/no-tools.

Explicit provider and model choices are authoritative. Automatic resolution
checks verified provider contracts and never invents public model endpoints.

Provider/model metadata is stored at
`~/.local/share/nvim/codetyper/configuration.json`. Secret values, OAuth
tokens, request headers, account identity, and residency are not persisted.

## Canonical agent tools

The registry in `core/agent/tools/init.lua` owns exactly six names:

```text
codegraph_context(query,max_nodes,no_code)
tokensave_search(query,limit)
context7_resolve_library(query)
context7_query_docs(library_id,query)
ask_user(question,options)
add_import(path,statement)
```

All native calls and text markers use bounded validation and the result shape
`{status,data,error,stale}`. Encoded results are limited to 4000 characters.
Unknown names, extra fields, invalid ranges, control characters, and malformed
objects have no side effects.

### CodeGraph

The adapter checks the executable, validates the absolute project root, and
runs status before a read-only query. The only command shapes are equivalent
to:

```text
codegraph status --json <root>
codegraph context <query> --path <root> --format json --max-nodes <n> [--no-code]
codegraph explore <query> --path <root> --format json --max-nodes <n> [--no-code]
```

Uninitialized projects are `unavailable`; pending, indexing, or stale indexes
are `stale`; malformed output is an error. The adapter never runs `init`,
`sync`, `index`, `daemon`, or database operations.

### TokenSave

The adapter requires `.tokensave/config.json`, `.tokensave/branch-meta.json`,
an absolute matching root, a current mapped Git branch, and ready status. It
runs only:

```text
git -C <root> branch --show-current
```

It accepts bare JSON and the observed `content[].text` double-encoded envelope.
Unmapped branches, stale indexes, malformed markers, invalid JSON, or unsafe
database paths fail closed. It never opens or assumes a TokenSave database.

### Context7

MCPHub is tried first under the `context7` alias. The fallback uses only
`https://mcp.context7.com/mcp` and the read-only Streamable HTTP surface:

```text
initialize
notifications/initialized
```

The fallback retains `Mcp-Session-Id`, accepts JSON/SSE responses, bounds body
and timeout values, and supports cancellation. `CONTEXT7_API_KEY` is read in
memory only. URLs, headers, session IDs, payloads, and credentials are removed
from result metadata and errors.

### Imports and interaction

`add_import` plans a single declaration for JavaScript/TypeScript, Python, Lua,
Go, Rust, C/C++, Java/Kotlin, Ruby, or PHP. It preserves headers/package
metadata, deduplicates equivalent declarations, respects open-buffer content,
and rejects traversal, absolute paths, documentation files, remote references,
multiline statements, unsupported languages, and ambiguous declarations.

`ask_user` renders a bounded selectable float with at most eight options.
`<Up>`/`<Down>` move, `<CR>` selects, and `<Esc>` cancels. Interactive and
mutating calls are FIFO-serialized and complete exactly once.

## Dispatch contracts

The parser recognizes these local markers and maps them to the same registry:

```text
TOOL:CODEGRAPH {"query":"request","max_nodes":20}
TOOL:TOKENSAVE {"query":"request","limit":10}
TOOL:CONTEXT7_RESOLVE {"query":"neovim"}
TOOL:CONTEXT7_QUERY {"library_id":"/neovim/neovim","query":"autocmd"}
TOOL:ASK_USER {"question":"Continue?","options":["Yes","No"]}
TOOL:ADD_IMPORT {"path":"lua/app.lua","statement":"local M = {}"}
```

Malformed, double-encoded, array-shaped, unknown, or extra-field marker
payloads are ignored or rejected before execution. Native structured calls and
markers use one executor. Local registry tools run before external MCP calls;
results are bounded, cancellable, serialized where necessary, and protected
against late callbacks.

Terminal calls remain a separate visible boundary with dangerous command
patterns blocked. MCP calls use the installed allowlist and exclude filesystem
and shell operations that overlap with file markers or the terminal.

## Prompt and context flow

```text
user selection/tag
  -> intent and scope resolution
  -> synchronous local context snapshot
  -> capability-aware prompt tier
  -> explicit provider selection
  -> native Copilot dispatch or text-marker dispatch
  -> bounded executor/adapter
  -> reviewable buffer or file result
```

Prompt construction advertises only explicitly available tools, fixed limits,
safe statuses, and capability mode. It does not probe MCP or execute tools while
assembling context. Context gathering uses injected snapshots and remains
synchronous; external work is model-invoked through the executor boundary.

## Persistent project data

The plugin may maintain project index and memory data under `.codetyper/` when
those features are enabled, plus cost history at `.codetyper/cost_history.json`.
These files contain project context or usage metadata, not provider secrets.
The plugin does not create or modify a project's `.gitignore` by default.

## Commands and configuration

The main dispatcher is `:Coder` with `version`, `reset`,
`transform-selection`, `index-project`, `index-status`, `llm-stats`,
`llm-reset-stats`, `cost`, `cost-clear`, `terminal`, `queue`, `autotrigger`,
`process`, `credentials`, `switch-provider`, `model`, and `auth` subcommands.
OpenAI auth is available as `:Coder auth openai browser` or
`:Coder auth openai device`.

Default mappings are `<leader>ctt` (transform), `<leader>ctm` (model), and
`<leader>ter` (terminal). Inline tags default to `/@` and `@/`; the canonical
companion pattern is `*.codetyper.*`.

## Testing boundary

Tests run in headless Neovim with Plenary. HTTP, CLI, MCPHub, provider, popup,
buffer, and cancellation seams use injected fakes. The suite does not require
network access, credentials, installed CodeGraph/TokenSave binaries, an MCP
server, or a database.

```text
make test
make test-file FILE=tests/spec/context7_spec.lua
make lint
make format-check
make docs
```
